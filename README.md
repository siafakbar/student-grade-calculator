# Student Grade Calculator

A simple Python application that calculates a student's average marks
and determines whether the student has passed or failed.

## Version

1.1.0

## Requirements

- Python 3.x
- No external packages required

## Usage

    python grade_calculator.py

Enter the student's name and marks for five subjects when prompted.

## Output

The program displays:
- Student name
- Average marks
- Result (PASS or FAIL)
